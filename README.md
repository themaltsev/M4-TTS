# Озвучивание выделенного текста для Ubuntu GNOME и Windows

Небольшой Linux-проект для MacBook с Ubuntu: выдели текст и нажми **Super (⌘ на клавиатуре Mac) + Escape**. Скрипт получает речь через Edge TTS и сразу передаёт поток в `mpv`, не дожидаясь загрузки всего аудиофайла. Текст отправляется в онлайн-сервис Microsoft Edge TTS.

## Установка после клонирования

Запусти команды **из Терминала внутри графического сеанса Ubuntu**:

```bash
git clone https://github.com/themaltsev/ozvuchka-videlenogo-teksta.git
cd ozvuchka-videlenogo-teksta
./install.sh
```

Установщик поставит системные зависимости через `sudo apt`, создаст отдельное окружение `edge-tts` через `pipx`, установит команды и ресурсы в `~/.local`, включит AppIndicator (если Ubuntu предоставляет расширение) и назначит `Super+Escape`. Установка пакетов запрещает удаление и обновление уже установленных системных пакетов; если зависимостей не хватает и пакетный менеджер предлагает такие изменения, apt безопасно остановится. `install.sh` запускай обычным пользователем, **не** через `sudo`.

Если сочетание клавиш не заработало сразу, выйди из сеанса GNOME и войди снова. На раскладке Mac клавиша Command обычно отображается как Super.

## Windows

Для Windows 10/11 установи Python 3 (с `py` launcher), затем открой PowerShell в папке репозитория и выполни:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\windows\install.ps1
```

Установщик создаст отдельное окружение, поставит Edge TTS и зависимости и добавит команды в пользовательский PATH. При входе в Windows автоматически появится значок в трее: во время ожидания в нём отображаются часы и секунды, после начала воспроизведения — эквалайзер. Наведи курсор, чтобы увидеть состояние и точное время; в меню значка доступны остановка речи и выход.

Хоткей задаётся в `%APPDATA%\selected-text-speech\config.env`, например `HOTKEY=ctrl+alt+s` или `HOTKEY=ctrl+shift+f9`. После изменения закрой старый значок через его меню и запусти `selected-text-speech-tray.cmd` из нового терминала. Также доступны `speak "текст"`, `speak-selection`, `stop-speech` и `speak-status`.

Для удаления запусти `windows\uninstall.ps1` из PowerShell. По умолчанию он удалит утилиту вместе с настройками; параметр `-KeepConfig` сохранит пользовательский конфиг.

Windows-версия временно копирует выделение через Ctrl+C. Текстовую часть прежнего буфера обмена она восстанавливает после чтения; прочие форматы буфера (например, изображение) не сохраняются. В отличие от Linux-версии, Windows сначала получает целый аудиофрагмент Edge TTS и затем проигрывает его — поэтому начало речи может задержаться. Журнал — в `%LOCALAPPDATA%\selected-text-speech\state\tts.log`.

## Запуск и остановка

Команды теперь разделены по назначению:

```bash
speak "текст для озвучивания"  # запустить озвучивание указанного текста
cat article.txt | speak       # принять текст из stdin
speak-selection               # озвучить выделение; повторное нажатие останавливает
stop-speech                    # остановить озвучивание
speak-status                   # проверить состояние
```

Горячая клавиша вызывает `speak-selection`. `speak` — явный запуск для переданного текста, `stop-speech` — отдельная остановка, а `speak-selection` сохраняет toggle-поведение для горячей клавиши.

## Что показывается в панели

Во время подготовки Edge TTS отображаются секунды ожидания и иконка часов. Когда приходят первые аудиоданные, секунды сменяются иконкой эквалайзера. До начала речи воспроизводятся тихие сигналы ожидания; завершение или отмена убирает индикатор.

## Настройка голоса и звуков

Корневой `config.env` — шаблон настроек, который `install.sh` копирует при первой установке в `~/.config/selected-text-speech/config.env`. Изменяй именно установленную копию, чтобы настройки сразу применялись:

- `EDGE_TTS_VOICE` — голос, например `ru-RU-SvetlanaNeural`
- `EDGE_TTS_RATE`, `EDGE_TTS_VOLUME`, `EDGE_TTS_PITCH` — темп и параметры синтеза Edge TTS
- `EDGE_TTS_CONNECT_TIMEOUT`, `EDGE_TTS_RECEIVE_TIMEOUT` — сетевые таймауты API
- `MPV_PLAYBACK_SPEED`, `MPV_PLAYBACK_VOLUME` — скорость и громкость проигрывателя
- `CUE_VOLUME`, `TICK_VOLUME_DB` — громкость сигналов запуска/отмены и тихого тика
- `API_MAX_ATTEMPTS`, `API_RETRY_BASE_SECONDS`, `API_RETRY_MAX_SECONDS` — ограниченные повторы API без аудио с экспоненциальной паузой
- `START_SOUND`, `CANCEL_SOUND`, `TICK_SOUND` — файлы звуков; по умолчанию берутся из `~/.local/share/selected-text-speech/sounds/`

Системные сигналы запуска и отмены скопированы в репозиторий, а их источники и лицензии указаны в [`SOURCES.md`](linux-gnome/share/sounds/SOURCES.md). Повторный запуск установщика не перезаписывает существующий пользовательский `config.env`.

### Если Edge TTS временно не прислал аудио

В журнале клиента зафиксирован `NoAudioReceived` до первого аудиофрагмента; в том же запуске повторная попытка затем получила аудио. Такая ошибка наблюдается и у других пользователей `edge-tts 7.3.1`: сервер иногда заканчивает WebSocket-запрос без аудио. Поэтому Python-клиент повторяет только неуспешные попытки до первого аудиофрагмента, с ограниченной экспоненциальной паузой. Если звук уже пошёл, повторного проигрывания не будет. Журнал по пути `$XDG_RUNTIME_DIR/macbook-tts-$UID/tts.log` содержит номер попытки, длительность и тип ошибки, но не сохраняет переданный текст. [Upstream issue](https://github.com/rany2/edge-tts/issues/512).

## Требования

- Ubuntu с GNOME и активным графическим сеансом
- соединение с интернетом для Edge TTS
- доступное аудиоустройство

Установщик ставит `mpv`, `pipx`, GTK/Ayatana bindings, `wl-clipboard` и `xclip`, системные звуки и уведомления. На Wayland используется `wl-paste`, на X11 — `xclip` (с `xsel` тоже совместимо).

## Устройство проекта

- `linux-gnome/bin/speak` — Python CLI, принимает текст аргументом или из stdin
- `linux-gnome/bin/stop-speech` — отдельная команда остановки
- `linux-gnome/bin/speak-selection` — интеграция выделения с GNOME и toggle по горячей клавише
- `linux-gnome/src/selected_text_speech/` — Python-модули конфигурации, API-потока, аудиоплеера, таймера и панели
- `config.env` — корневой шаблон конфигурации
- `install.sh` — установка Linux-версии и сочетания GNOME
- `windows/install.ps1` и `windows/speech.py` — установщик и runtime Windows
