# Озвучивание выделенного текста для Ubuntu GNOME

Небольшой Linux-проект для MacBook с Ubuntu: выдели текст и нажми **Super (⌘ на клавиатуре Mac) + Escape**. Скрипт получает речь через Edge TTS и сразу передаёт поток в `mpv`, не дожидаясь загрузки всего аудиофайла. Текст отправляется в онлайн-сервис Microsoft Edge TTS.

## Установка после клонирования

Запусти команды **из Терминала внутри графического сеанса Ubuntu**:

```bash
git clone https://github.com/themaltsev/ozvuchka-videlenogo-teksta.git
cd ozvuchka-videlenogo-teksta
./install.sh
```

Установщик поставит системные зависимости через `sudo apt`, создаст отдельное окружение `edge-tts` через `pipx`, установит команды и ресурсы в `~/.local`, включит AppIndicator (если Ubuntu предоставляет расширение) и назначит `Super+Escape`. Установка пакетов запрещает удаление и обновление уже установленных системных пакетов; если зависимостей не хватает и пакетный менеджер предлагает такие изменения, apt безопасно остановится. `install.sh` запускай обычным пользователем, **не** через `sudo`.

Если сочетание клавиш не заработало сразу, выйди из сеанса GNOME и войди снова. На раскладке Mac клавиша Command обычно отображается как Super.

## Запуск и остановка

Главная команда — `speak-selection`:

```bash
speak-selection          # то же, что toggle: запустить или остановить
speak-selection start    # начать; если уже работает — оставить как есть
speak-selection stop     # остановить текущую озвучку
speak-selection status   # показать состояние
```

Горячая клавиша вызывает `speak-selection toggle`. Второе нажатие останавливает текущую озвучку. `start` читает текущее выделение; проверь, что оно не пустое.

## Что показывается в панели

Во время подготовки Edge TTS отображаются секунды ожидания и иконка часов. Когда приходят первые аудиоданные, секунды сменяются иконкой эквалайзера. До начала речи воспроизводятся тихие сигналы ожидания; завершение или отмена убирает индикатор.

## Настройка голоса и звуков

Корневой `config.env` — шаблон настроек, который `install.sh` копирует при первой установке в `~/.config/selected-text-speech/config.env`. Изменяй именно установленную копию, чтобы настройки сразу применялись:

- `EDGE_TTS_VOICE` — голос, например `ru-RU-SvetlanaNeural`
- `EDGE_TTS_RATE`, `EDGE_TTS_VOLUME`, `EDGE_TTS_PITCH` — темп и параметры синтеза Edge TTS
- `MPV_PLAYBACK_SPEED`, `MPV_PLAYBACK_VOLUME` — скорость и громкость проигрывателя
- `CUE_VOLUME`, `TICK_VOLUME_DB` — громкость сигналов запуска/отмены и тихого тика
- `START_SOUND`, `CANCEL_SOUND`, `TICK_SOUND` — файлы звуков; по умолчанию берутся из `~/.local/share/selected-text-speech/sounds/`

Системные сигналы запуска и отмены скопированы в репозиторий, а их источники и лицензии указаны в [`SOURCES.md`](linux-gnome/share/sounds/SOURCES.md). Повторный запуск установщика не перезаписывает существующий пользовательский `config.env`.

## Требования

- Ubuntu с GNOME и активным графическим сеансом
- соединение с интернетом для Edge TTS
- доступное аудиоустройство

Установщик ставит `mpv`, `pipx`, GTK/Ayatana bindings, `wl-clipboard` и `xclip`, системные звуки и уведомления. На Wayland используется `wl-paste`, на X11 — `xclip` (с `xsel` тоже совместимо).

## Файлы

- `linux-gnome/bin/speak-selection` — переключатель/контроллер запуска и остановки
- `linux-gnome/bin/edge-tts-stream.py` — запрос к Edge TTS и потоковая передача аудио
- `linux-gnome/bin/tts-panel-indicator.py` — таймер и индикатор панели GNOME
- `install.sh` — установка зависимостей, файлов и сочетания клавиш
